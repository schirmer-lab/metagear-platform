<section class="mg-sec mg-reveal" id="pipeline">
  <div class="mg-sec__rail"><span class="mg-sec__num">PIPELINE</span></div>
  <div class="mg-sec__body">
    <div class="mg-sec__head">
      <span class="mg-eyebrow">MetaGEAR Pipeline</span>
      <h2 class="mg-feature__title">
        One Nextflow pipeline, <em>ten composable workflows.</em>
      </h2>
      <p class="mg-feature__lead">
        Built on nf-core conventions. Profile a cohort against reference
        databases, or assemble it and get gene catalogs, viruses, bacterial
        genomes, species pangenomes and protein structures — reproducibly, on a
        laptop or an HPC cluster.
      </p>
    </div>

    <PipelineFigure />
    <p class="mg-fig-hint">Scroll the figure sideways to see the full width.</p>

    <div class="mg-sec__foot">
      <ul class="mg-feature__points mg-points--grid">
        <li><strong>Gene- and genome-resolved together.</strong> One assembly yields the
        cohort gene catalog and the dereplicated MAGs.</li>
        <li><strong>Viruses and plasmids alongside.</strong> Detection, host prediction and
        viral-specific annotation, not an afterthought.</li>
        <li><strong>Structures for the dark matter.</strong> 3Di prediction and structural
        search reach proteins no sequence method annotates.</li>
        <li><strong>Presets share the expensive work.</strong> Later workflows read what
        earlier ones produced instead of recomputing it.</li>
      </ul>
      <div class="mg-feature__meta">
        <span>10 workflows</span><span>58 modules</span><span>Nextflow &ge; 25</span>
        <span>Docker or Singularity</span><span>MIT-licensed</span>
      </div>

{/* ===================== 02 · EXPLORER ===================== */}
<section class="mg-sec mg-reveal" id="explorer">
  <div class="mg-sec__rail"><span class="mg-sec__num">EXPLORER</span></div>
  <div class="mg-sec__body">
    <div class="mg-sec__head">
      <span class="mg-eyebrow">MetaGEAR Explorer</span>
      <h2 class="mg-feature__title">
        Query bacterial genes against <em>cohorts the pipeline already processed.</em>
      </h2>
      <p class="mg-feature__lead">
        Explorer serves the gene catalogs produced by the pipeline above. Bring a
        sequence, a Pfam domain, or an MSP identifier and get back where it shows up
        across uniformly-processed cohorts — with cohort and sample metadata attached
        to every result.
      </p>
    </div>

    <a class="mg-shot" href="https://metagear-explorer.schirmerlab.de">
      <img
        src="/explorer-screenshot.webp"
        alt="MetaGEAR Explorer landing page: gene-centric search across published microbiome cohorts, with counts for gene families, cohorts, stool samples and species pangenomes."
        loading="eager"
        width="2200"
        height="1580"
      />
    </a>

    <div class="mg-sec__foot">
      <ul class="mg-feature__points mg-points--grid">
        <li><strong>BLAST</strong> a nucleotide or protein sequence against cohort-wide gene catalogs.</li>
        <li><strong>Browse by Pfam domain</strong> (e.g. <code>PF08020</code>) to find every gene that contains it.</li>
        <li><strong>Explore MSPs</strong> — curated Metagenomic Species Pangenomes.</li>
        <li><strong>Filter by cohort</strong>: IBD, CRC, healthy controls. Every hit traces back to its sample.</li>
      </ul>
      <div class="mg-feature__meta">
        <span>No install</span><span>Free hosted service</span><span>Seconds to first hit</span>
      </div>

{/* ===================== 03 · TOOLS (CLI) ===================== */}
<section class="mg-sec mg-reveal" id="tools">
  <div class="mg-sec__rail"><span class="mg-sec__num">TOOLS</span></div>
  <div class="mg-sec__body">
    <div class="mg-sec__head">
      <span class="mg-eyebrow">MetaGEAR Tools · CLI</span>
      <h2 class="mg-feature__title">
        Install the pipeline. <em>Run a workflow.</em> Skip the Nextflow learning curve.
      </h2>
      <p class="mg-feature__lead">
        A small command-line wrapper that installs the pipeline, detects your
        hardware, manages reference databases, and runs workflows and presets with
        one command.
      </p>
    </div>

    <div class="mg-terminal" role="img" aria-label="Terminal showing MetaGEAR Tools install and run commands.">
      <div class="mg-terminal__chrome">
        <span class="mg-terminal__dot"></span>
        <span class="mg-terminal__dot"></span>
        <span class="mg-terminal__dot"></span>
        <span class="mg-terminal__title">~/projects/microbiome</span>
      </div>
      <div class="mg-terminal__body">
        <div><span class="comment"># Install MetaGEAR (one-time)</span></div>
        <div><span class="prompt">$</span> <span class="cmd">curl -L http://get-metagear.schirmerlab.de | bash</span></div>
        <div><span class="out">→ installed to ~/.metagear · 36 CPUs / 64 GB detected</span></div>
        <div>&nbsp;</div>
        <div><span class="comment"># Download reference databases</span></div>
        <div><span class="prompt">$</span> <span class="cmd">metagear download_databases</span></div>
        <div>&nbsp;</div>
        <div><span class="comment"># Run a preset end to end</span></div>
        <div><span class="prompt">$</span> <span class="cmd">metagear microbiome --input samples.csv</span></div>
        <div><span class="out">→ genes → virus → classification → mag → msp on </span><span class="accent">12 samples</span><span class="out">…</span></div>
      </div>
    </div>

    <div class="mg-sec__foot">
      <ul class="mg-feature__points mg-points--grid">
        <li><strong>Hardware-aware</strong>: sets resource limits to ~80% of available CPUs and RAM.</li>
        <li><strong>Version-locked</strong>: installs the matching pipeline release.</li>
        <li><strong>Presets built in</strong>: one command runs a whole chain in order.</li>
        <li><strong>Multi-machine</strong>: <code>metagear cluster</code> spreads a cohort across nodes.</li>
      </ul>
      <div class="mg-actions">
        <a class="mg-btn mg-btn--primary" href="/tools/">Install MetaGEAR Tools →</a>
        <a class="mg-btn mg-btn--link" href="https://github.com/schirmer-lab/metagear-tools">View source ↗</a>
      </div>
    </div>
  </div>
</section>
